## ✦ Overview

A premium, responsive tattoo studio website designed around **visual storytelling, strong branding, artist presentation, and a smooth booking experience**.

The interface combines modern typography, immersive layouts, responsive interactions, and subtle animations to create a high-end digital experience.

---

## ✨ Highlights

* Premium responsive design
* Artist showcase
* Tattoo gallery
* Booking-focused experience
* Modern typography and layouts
* Smooth scrolling interactions
* Interactive hover states
* Mobile-friendly UI
* Performance-conscious animations

---

## 🎯 Experience

The website is structured around a simple customer journey:

```text
Discover
   ↓
Explore Artists
   ↓
View Work
   ↓
Build Trust
   ↓
Book a Session
```

The design focuses on keeping the experience visually engaging while making the important actions easy to find.

## 🚀 Run Locally

```bash
git clone https://github.com/Sanjai-Gopal/Tattoo2.git
cd Tattoo2
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
